# Phase 0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the minimal Phase 0 frontend/Worker scaffold and prove the bounded Internet Archive request path without deploying or implementing later phases.

**Architecture:** Vite compiles a vanilla TypeScript client into `dist`, which Cloudflare Workers Static Assets serves. A Worker handles only `/api/*`, validates the requested hostname, and calls the fixed Internet Archive CDX endpoint through a small provider with a result cap and timeout.

**Tech Stack:** Node.js 24, TypeScript, Vite, Vitest, Wrangler, Cloudflare Workers Static Assets

**Spec:** `docs/superpowers/specs/2026-11-01-phase-0-design.md`

## Global Constraints

- Implement Phase 0 only; timeline grouping and all later-phase features remain out of scope.
- No database, accounts, authentication, telemetry, paid services, credentials, or deployment.
- The Worker contacts only fixed Internet Archive hosts and never acts as an arbitrary URL proxy.
- Live provider calls are bounded to five CDX rows with an eight-second timeout.
- Deterministic tests use injected fetch functions and a clearly labelled fixture; CI never requires the live archive.
- Keep dependencies to the specified development/build toolchain and use no frontend framework.

## Review Focus

- Pasted homepage URLs with paths must reduce to the hostname rather than broadening the archive query.
- Credentials, ports, IP literals, localhost, internal names, and malformed labels must be rejected before fetch.
- A malformed CDX header or row must produce an explicit upstream-data error rather than partial invented data.
- A 429 response must remain distinguishable from a general upstream failure.
- Client rendering must use text nodes/`textContent`, never archive metadata in `innerHTML`.
